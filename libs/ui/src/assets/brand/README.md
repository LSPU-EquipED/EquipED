# EquipED identity — Folio

Folio is the selected product identity: an E formed from a folded module page, with a secondary page behind it. The LSPU emblem identifies institutional affiliation and remains a separate asset. The shared sidebar, authentication brand panel, and both portal favicons use Folio.

## Assets

| Usage | Full logo | Symbol |
| --- | --- | --- |
| Light surfaces | equiped-logo.svg | equiped-symbol.svg |
| Single-color reproduction | equiped-logo-monochrome.svg | equiped-symbol-monochrome.svg |
| Dark surfaces | equiped-logo-reversed.svg | equiped-symbol-reversed.svg |

The expanded sidebar assembles `equiped-symbol.svg` and `equiped-wordmark.svg` horizontally, with its institutional caption above the wordmark.

All files have transparent backgrounds. Use the complete logo where the name needs to be visible and the symbol where space is limited. Preserve the aspect ratio, keep at least one quarter of the symbol width clear around the mark, and avoid effects or additional colors. Use the supplied reversed version on dark surfaces.

The palette follows DESIGN.md: royal blue #1b3b87, amber #d9ad1d, ink #1b2b33, and surface #fbfcfc. Wordmarks use the existing Public Sans SemiBold font, embedded in each full-logo SVG for browser rendering. Symbols contain paths only. For a print workflow requiring outlined lettering, outline the wordmark in the receiving vector editor before export. Font license: ../fonts/PublicSans-OFL.txt.

Unselected concepts have been removed; this directory contains only the adopted Folio identity.
