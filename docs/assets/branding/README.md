# README branding

The README uses a single **EquipED × LSPU** lockup. The Folio symbol replaces the
first E in EquipED; the university emblem and LSPU lettering form the institutional
side. The emblem remains separate from the product identity.

- `equiped-lspu.svg`: royal-blue lettering for light backgrounds.
- `equiped-lspu-dark.svg`: reversed lettering for dark backgrounds.

These are documentation assets. Application logos remain under
[`libs/ui/src/assets/brand`](../../../libs/ui/src/assets/brand/).

Both SVGs contain outlined Public Sans SemiBold lettering and an embedded copy of
the existing university emblem, optimized for this display size. They require no
external fonts or image requests. Preserve their aspect ratio. The font license is
[`PublicSans-OFL.txt`](../../../libs/ui/src/assets/fonts/PublicSans-OFL.txt).
