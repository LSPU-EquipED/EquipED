# ITSO simplified harness operation

Current implementation uses adapter 3: the existing five-criterion advisory rubric pipeline and scorecard, with required backend public-reference search and available source-page retrieval for criteria 1 and 2 on every new run. Policy approval, attachment and fact-adjudication interfaces have been retired. Historical adapter-2 evidence-only assessments remain readable and keep their withheld scores. Applied migrations are historical schema records and must remain available; no tables or saved evaluations are deleted by this cleanup.

## Runtime

Every new ITSO evaluation requires the existing configured model and `ITSO_VERIFICATION_ENABLED=true` in the server environment. Current search uses DuckDuckGo's public HTML interface without an API key. Retired adapter-1/2 execution, consent/preflight services and browser/VM tooling have been removed; historical result readers remain. There is no per-run opt-out or offline completion path. New tool execution uses bounded pinned HTTPS requests and HTML parsing; it does not need a downloaded VM, Chromium or `bwrap`. Dynamic, blocked or inaccessible source pages remain explicitly unavailable. Public reference matches support the scoped advisory review and do not prove exhaustive plagiarism clearance.

External access is checked at admission and again during execution. A run fails if the required search service is unavailable, no safe query fields can be extracted, or no usable public source passage is retrieved. Queries contain recognized public bibliography details, including numbered author/work citations under Learning resources, or explicitly labelled lesson/topic names when no safely identifiable citations are detected. Learning resources is an accepted acknowledgement section; hyperlinks are optional. Extracted citation metadata is labelled separately from retrieved source metadata so a found page is not mistaken for an existing module citation. Topic searches report missing citations and supply external context; they do not verify citation identity or absence of plagiarism. Private body passages and personal data are excluded. Individual inaccessible source pages can remain unverified with a stated limit when another usable source passage was retrieved; they are never fabricated as matches. Adapter 3 excludes legacy internal-only prompt templates and requires source citations in the model response for both criteria and explicit reporting when a bibliography was not detected, with one bounded repair before failure. The current harness uses two fixed rubric requests under one model deadline: criteria 1–2 compare short verbatim module passages with independent public sources; criteria 3–5 evaluate the module text. Both requests must pass. The existing criterion reasoning preserves bounded source links, retrieved passages and coverage limits independently of model omissions, while saved model generations remain faithful to the original responses and retain the complete bounded tool report. Any display omissions are explicit. Reference count, source candidates, two-hop validated HTTPS redirects, response size and execution deadlines remain bounded, with coverage and request attempts recorded explicitly. Ignored request extras or older saved provenance cannot disable current verification; the pure harness also rejects disabled, empty or wholly unusable verification reports before model transport.

## Verification limits

The owner selected credential-free search and topic-name fallback for modules without bibliographies. Local external search is now enabled. DuckDuckGo HTML is a public search interface rather than a guaranteed machine API; challenge pages, unexpected markup and outages fail explicitly. Fake-I/O tests verify mandatory execution, provider/search/page handling, privacy boundaries and failure behavior. Browser surfaces are unavailable in this session; rendered UI verification is separate from component tests and production builds.

Before the local configuration change, a live admission check returned HTTP 503 (`verification_disabled`) for both omitted and explicitly false verification request flags and created no evaluation jobs. Its receipt is retained in the owner-only audit directory. That receipt verifies the historical configuration block, not the current configured search path.

Bibliography detection is conservative: ambiguous lines end the detected section rather than allowing later SLM content to become a search query. Unsupported citation layouts may therefore remain unverified. Coverage describes detected references and does not establish an exhaustive document audit.
