# Roadmap Seeds

This directory stores structured roadmap seed payloads. Source PDFs are provenance-only and are never embedded.

The BSCS seed source name and BSIT seed source URL are: https://docs.google.com/document/d/1PYySC_rpB9V_SAuPC6uT0lWjIQ7aJq384nesPjh5Nrg/edit

`BSIT` in the source payload canonicalizes to stored `BSInfoTech`.

Explicit source omissions (not accidental) are `ITEP 203` Quantitative Methods (no year/semester), `ITEP 310` Social and Professional Issues (no year/semester), and `ITEP 312` Capstone Project 1 (Year 3 suggested elsewhere but semester unspecified). They must be added only after authoritative placement is supplied.

Repeated source rows for ITEC 101–103 were deduplicated.
