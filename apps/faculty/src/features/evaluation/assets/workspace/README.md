# Specialist workspace assets

The evaluation feature owns these eleven self-contained SVGs. Dashboard specialist
icons belong to the home feature; the shared faculty archive retains the earlier
concepts and generation prompts.

## Illustrations

`illustrations/` contains four distinct landing scenes:

- `content-inspection.svg`: manuscript and magnifier.
- `curriculum-planning.svg`: curriculum board.
- `inclusive-discussion.svg`: colleagues exchanging perspectives.
- `innovation-workbench.svg`: prototype and source folio.

`module-dossier.svg` supports module setup and unknown progress status.
`workspace-unavailable.svg` accompanies retrieval errors, and
`review-interrupted.svg` accompanies failed evaluations. These visuals use flat
fills, royal-blue outlines, and the connected amber Folio fold. They carry no
invented scores, document content, or approval marks.

## Animations

`animations/` contains `queued.svg`, `preparation.svg`, `specialist-review.svg`,
and `finalizing.svg`: a waiting tray, assembly frame, inspection lens, and findings
folder. Each scene loops within one server-reported state. It never advances the
stage or implies a score, approval, completion percentage, or duration.

`StageArtwork` inlines these trusted local SVGs for pause/resume controls.
Reduced-motion preferences disable the animation. Accessible status text remains
the interface's responsibility. Keep SVG colors self-contained and preserve view
boxes and keyframes when moving files.
