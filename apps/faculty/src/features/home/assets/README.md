# Dashboard assets

These six SVGs belong to the faculty home feature and are grouped by the component
that uses them:

| Folder | Asset | Consumer |
| --- | --- | --- |
| `welcome/` | `welcome-folds.svg` | `FacultyWelcomeBanner` |
| `modules/` | `module-collection.svg` | `FacultyModuleOverview` |
| `specialists/` | `content-review.svg`, `curriculum-review.svg`, `inclusive-review.svg`, `innovation-review.svg` | `FacultyWorkspaces` |

The specialist illustrations are the compact dashboard family. Larger workspace
scenes and motion belong to the evaluation feature. Shared alignment artwork and
the reusable paper texture stay under `src/assets/`, while design studies and
prompts stay in its `explorations/` collection.

Preserve SVG contents, view boxes, and the institutional palette when reorganizing
files. Artwork is decorative; accessible labels come from the component content.
